# Mirage Academy

منصة تعليمية عربية متجاوبة مبنية بـ HTML وCSS وJavaScript، وتعتمد على ملف data.json لإدارة المدرسين والفصول والمحاضرات.

## المميزات

- تصميم عربي RTL متوافق مع الهاتف والكمبيوتر.
- بحث في أسماء المدرسين والمواد والمحاضرات.
- صفحات للمدرسين والفصول وتشغيل المحاضرات.
- حفظ التقدم والمفضلة على جهاز المستخدم.
- وضع داكن وفاتح.
- دعم التثبيت كتطبيق PWA.
- نشر تلقائي عبر GitHub Pages.

## تعديل المحتوى

كل المحتوى موجود داخل data.json وفق التسلسل:

teachers ثم classes ثم lectures.

بعد تعديل الملف ورفعه إلى فرع main سيُعاد نشر المنصة تلقائيًا.

## التشغيل المحلي

يجب تشغيل المشروع عبر خادم ويب محلي لأن المتصفح قد يمنع قراءة data.json عند فتح index.html مباشرة.

مثال:

    python -m http.server 8080

ثم افتح:

    http://localhost:8080

## ملاحظة

تأكد من امتلاك حق استخدام ونشر روابط المحاضرات والصور الموجودة في ملف البيانات.
